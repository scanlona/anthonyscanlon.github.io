BEAT UP CANCER

BEAT UP CANCER is a fast-paced 2D arcade-fighting game built in Unity as a collaborative Senior Capstone Project for Seattle Pacific University. Engineered by Radioactive Studios, the project features responsive state-machine controls and an optimized WebGL architecture for seamless, zero-install browser gameplay.
